# PRD

## Objective

Increase the percentage of roadmap decisions supported by representative user evidence.

## Target Users

Product Managers, Product Ops, Researchers, Growth PMs, Heads of Product, and B2B SaaS founders.

## Problem

High feedback volume can hide biased evidence from admins, enterprise customers, internal stakeholders, or high-revenue accounts.

## MVP Scope

CSV import, population modeling, evidence linking, scoring, blind-spot detection, recommendations, reports, demo data, tests, and documentation.

## Non-Goals

Generic feedback tracker, CRM replacement, sentiment-only app, and opaque AI decision maker.

## Acceptance Criteria

Users can import data, inspect distributions, score roadmap items, view blind spots, generate recommendations, export reports, configure weights, and run tests.
