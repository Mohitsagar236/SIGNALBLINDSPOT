# Data Model

Core entities are Organization, User, Account, EndUser, Feedback, Interview, RoadmapItem, RoadmapEvidenceLink, SegmentDefinition, CoverageScore, BlindSpot, ResearchRecommendation, DecisionReport, ScoringSetting, DecisionNote, ImportBatch, and ImportError.

The model supports many evidence links per roadmap item, many roadmap items per feedback/interview item, and auditable generated reports.
